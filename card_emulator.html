Потрібен HTTPS!
Web Bluetooth працює тільки через HTTPS.
Відкрити файл напряму (file://) — не спрацює.

Варіант 1 — Python сервер (найпростіше):
python3 -m http.server 8080
Потім в Chrome на телефоні відкрий:
http://<IP вашого ПК>:8080
Варіант 2 — GitHub Pages (HTTPS хостинг):
Завантаж файл на github.com → Settings → Pages → Deploy
Варіант 3 — ngrok тунель:
npx ngrok http 8080
